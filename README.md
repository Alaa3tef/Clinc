# 🌸 Lumière - Cosmetic & Laser Center Management System
### نظام إدارة مركز لوميير للتجميل والليزر (Angular + PrimeNG)

نظام إداري متكامل وشامل لعيادات ومراكز التجميل والليزر مبني بأحدث تقنيات **Angular** و **PrimeNG** ومطابق تماماً لتصميم لوحة التحكم المرفق.

---

## ✨ المميزات الرئيسية (Key Features)

1. **دعم كامل للغتين العربية والإنجليزية (Bilingual EN / AR) مع التبديل التلقائي لاتجاه الواجهة (RTL / LTR)**.
2. **شاشة تسجيل دخول فاخرة (Login)** متناسقة مع هوية العيادة وألوان الـ Mauve والـ Rose Gold.
3. **لوحة التحكم الرئيسية (Dashboard)**:
   - 4 بطاقات مؤشرات أداء رئيسية (KPIs): إجمالي المرضى، مواعيد اليوم، إيرادات اليوم، والمدفوعات المعلقة.
   - رسم بياني للإيرادات (Line Chart) على مدار العام.
   - رسم بياني دائري لتصنيفات العلاج (Doughnut Chart) مع النسب المئوية.
   - قائمة بالمواعيد القادمة وحالاتها (Confirmed, Pending).
   - بطاقة دعائية "بشرة صحية وجمال يمنحكِ الثقة".
4. **إدارة المرضى (Patients Management)**:
   - جدول المرضى مع البحث الفوري بالاسم أو الهاتف أو الكود.
   - نافذة تفاصيل ملف المريض الجانبية (Personal Info, Medical History, Treatments, Appointments, Payments, Notes).
   - إضافة مريض جديد مع شارة الـ VIP.
5. **جدولة المواعيد (Appointments Scheduling)**:
   - تقويم أسبوعي مجدول بالأوقات وساعات العمل (08:00 إلى 16:00).
   - بطاقات الحجوزات الملونة حسب نوع الخدمة.
   - نموذج الحجز السريع (Quick Book) لاختيار المريض، العلاج، الطبيب، الغرفة، والتوقيت.
6. **جلسات الليزر (Treatment Sessions)**:
   - شاشة تفاصيل الجلسة المطابقة للصورة بالكامل.
   - **معايير ضبط الجهاز (Parameters Grid)**:
     - الطاقة (Energy): `18 J/cm²`
     - مدة النبضة (Pulse Duration): `20 ms`
     - التردد (Frequency): `10 Hz`
     - حجم البقعة (Spot Size): `12 mm`
     - التبريد (Cooling Level): `Level 3`
     - نوع البشرة (Skin Type): `Fitzpatrick III`
   - مقارنة صور قبل وبعد الجلسة (Before / After Photo Comparison).
   - الملاحظات الطبية وسجل العلاج.
7. **أجهزة الليزر (Laser Devices)**:
   - إدارة أجهزة الليزر (Alma Soprano Titanium, Candela GentleMax Pro, Lumenis CO2 Laser, Asclepion Diode Laser).
   - تنبيهات الصيانة الدورية الذكية (Maintenance Due in 5 Days).
8. **المدفوعات والفواتير (Payments & Invoices)**:
   - جدول الفواتير وحالات السداد (Paid, Pending).
   - ملخص المدفوعات: الإجمالي (142,850 EGP)، المحصل (98,600 EGP)، والمتبقي (44,250 EGP).
   - تسجيل دفعة جديدة وطباعة الفواتير.
9. **فريق العمل (Staff & Permissions)**:
   - إدارة الأطباء، التقنيين، التمريض، وموظفي الاستقبال.
10. **التقارير والإحصائيات (Reports & Analytics)**:
    - تقرير الإيرادات الشهري (Bar Chart).
    - أكثر العلاجات طلباً مع نسب الإنجاز.
    - مؤشرات: معدل التحويل (72%)، معدل عدم الحضور (6%)، المواعيد الكلية، والمرضى الجدد.

## 🚀 كيفية تشغيل المشروع (How to Run)

في مجلد المشروع `d:\Alaa\Clinc`، قم بتشغيل الأمر التالي:

```bash
npm start
```
أو
```bash
ng serve
```

ثم افتح المتصفح على:
```
http://localhost:4200/
```

- يمكنك تسجيل الدخول بالضغط على زر **Login** في شاشة تسجيل الدخول.
- يمكنك التبديل بين اللغتين العربية والإنجليزية في أي وقت بالنقر على زر **English / العربية** في أعلى شريط الرأس (Header) أو في شاشة تسجيل الدخول، وسيتحول اتجاه الواجهة بالكامل فوراً بين **RTL** و **LTR**.
